# projects/

Scratch space. Everything here is temporary files used to generate videos.

**Video work here is not tracked by git — only this README is. Safe to delete
at any time.**

```
projects/<app>/<video>/
  flow.js          Playwright script that drives the app
  video.json       beats: timing, zooms, captions
  studio/src/      this video's own copy of the composition template (scaffolded
                   on creation; edit freely — see AGENTS.md "fork-on-create")
  raw/             footage.webm        (generated by `record`)
  render/          footage.mp4, props.json  (generated by `compose`/`studio`)
  out/             <video>.mp4         (generated by `compose`)
  .snapshots/      saved state zips + manifest.json (see AGENTS.md "Snapshots")
```

`<app>` is the `name` field in that app's `demo.yml`. `new` scaffolds the folder
(from the tracked `studio/` template); `record`, `studio` and `compose`
auto-scaffold it if it does not exist yet.

## Snapshots

To bookmark a working state, follow the exact recipes in
`<videolab>/AGENTS.md`, section **"Snapshots — save and restore a video's
state"**. Summary: zip everything in this folder except `.snapshots/` into
`.snapshots/<timestamp>_<label>.zip`, and record label + comment in
`.snapshots/manifest.json`. Restoring is destructive and all-or-nothing —
confirm with the user and follow the AGENTS.md recipe exactly. Do not invent
your own snapshot format or location.

Losing this folder costs you the scripts, not the videos you already exported —
copy anything worth keeping out of `out/` before deleting.

To reproduce everything from scratch: re-record each video from its app repo.
Note that re-scaffolding copies the *current* template — a video's customized
`studio/` copy is not recoverable that way, so keep or snapshot anything worth
keeping from it before deleting.

# projects/

Scratch space. Everything here is temporary files used to generate videos.

**Video work here is not tracked by git — only this README is. Safe to delete
at any time.**

```
projects/<app>/<video>/
  flow.js          Playwright script that drives the app
  video.json       timing, zooms, captions
  raw/             footage.webm        (generated by `record`)
  render/          footage.mp4, props.json  (generated by `compose`)
  out/             <video>.mp4         (generated by `compose`)
  .snapshots/      saved state zips + manifest.json (see AGENTS.md "Snapshots")
```

`<app>` is the `name` field in that app's `demo.yml`. `record` and `compose` create
these folders; nothing else should.

Losing this folder costs you the scripts, not the videos you already exported —
copy anything worth keeping out of `out/` before deleting.

To reproduce everything from scratch: re-record each video from its app repo.
